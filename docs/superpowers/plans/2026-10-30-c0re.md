# C0RE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build C0RE, a Rust gateway in front of the PC's Ollama that admits only keyed requests on a private (Tailscale) and a public (Funnel) entrance, with per-key reach, models and limits, a usage log, a CLI and an embedded web dashboard.

**Architecture:** One Rust crate with a library (all logic, unit-testable) and two thin binaries: `c0re` (console CLI + `serve`) and `c0re-svc` (windowless, for the logon task). Two axum routers share one `AppState`; which router answers is decided by the listening socket. A Svelte + TypeScript dashboard is built by Vite into `web/dist` and embedded with `rust-embed`. Everything is cross-compiled to `x86_64-pc-windows-gnu` and shipped as a zip.

**Tech Stack:** Rust 1.97 (`axum`, `tokio`, `reqwest` with streaming, `rusqlite` bundled, `sha2`, `argon2`, `subtle`, `clap`, `rust-embed`, `serde`/`serde_json`, `toml`, `tracing` + `tracing-appender`, `rand`), Svelte 5 + Vite + TypeScript + Vitest, Playwright (screenshots), mingw-w64 cross toolchain.

**Spec:** `docs/superpowers/specs/2026-10-30-c0re-design.md`

## Global Constraints

- Ollama upstream `http://127.0.0.1:11434`; C0RE never binds a non-loopback address except the PC's Tailscale IPv4 on the private port.
- Private entrance port **7070** (Tailscale IP + `127.0.0.1`); public entrance **127.0.0.1:7071**; Funnel HTTPS port **8443**.
- Key secret format `c0re_` + 43 base62 chars (≥ 256 bits); shown once; never logged.
- Key defaults — private: 60/min, 2000/day, 2 concurrent, `max_ctx` 8192, 20 MB body. Public: 20/min, 500/day, 1 concurrent, 8192, 8 MB.
- Reach values exactly `private`, `public`, `off`.
- Error body shape `{"error":{"code":"…","message":"…"}}`; codes used: `missing_key`, `invalid_key`, `key_disabled`, `key_not_public`, `body_too_large`, `bad_request`, `model_not_allowed`, `rate_limited`, `daily_cap`, `too_many_concurrent`, `too_many_failures`, `engine_offline`, `model_missing`, `not_found`.
- Usage log: no prompts, images or answers; delete rows older than 90 days; keep DB ≤ 100 MB (delete oldest first).
- Admin surface (dashboard, `/admin/api/*`) exists only on the private router; public router returns 404 for it.
- Fail closed: any internal error in key/policy checks rejects the request (500 `internal`, never forwarded).
- Data dir `%LOCALAPPDATA%\C0RE` on Windows; overridable with env `C0RE_HOME` (used by tests).
- No network calls besides Ollama and the local `tailscale` CLI. Dashboard: no third-party scripts/fonts, strict CSP.
- Dashboard follows `.claude/skills/apple-design/SKILL.md` (load it before Task 11) and passes its review with no Critical findings.
- **Deliberate deviation from spec §3.1:** key secrets are hashed with **SHA-256** (constant-time compare), not Argon2id. Secrets are 256-bit random, so a slow hash adds nothing but ~20–50 ms per request, which would break the < 50 ms success criterion. Argon2id stays for the admin password.

## Review Focus

1. **All public traffic arrives from 127.0.0.1 (Funnel's proxy)** — per-source failure blocking must use the `X-Forwarded-For` client address on the public router, or one bad actor blocks every public user. → Task 4 `failure_blocker_keys_public_by_forwarded_for`, Task 6 `public_failures_blocked_per_forwarded_client`.
2. **A client sends `num_ctx: 262144` (or a string)** — it must be clamped to `max_ctx` / removed, never forwarded, or the model spills to CPU for everyone. → Task 3 `clamps_num_ctx`, `removes_non_numeric_num_ctx`.
3. **A client disconnects mid-stream** — the upstream request must be cancelled and the key's concurrency slot freed, or the key locks itself out. → Task 6 `disconnect_frees_concurrency_slot`.
4. **Malformed JSON or missing `model`** — reject with 400 before Ollama sees it. → Task 6 `malformed_body_rejected_not_forwarded`.
5. **Tailscale not up when C0RE starts** — serve on 127.0.0.1 only, keep retrying, and bind the Tailscale IP when it appears. → Task 7 `binds_tailscale_ip_when_it_appears`.
